Sloth Brain Shorts - Privacy Policy

Last updated: 28 October 2026

Sloth Brain Shorts is a private tool used only by the owner of the Sloth Brain YouTube channel (youtube.com/@TheSlothBrain) to upload short videos to that channel. It is not offered to the public.

What it accesses

The tool requests one Google permission, youtube.upload, which lets it upload videos to the signed-in user's own YouTube channel. It does not read email, contacts, files or any other Google account data.

What it stores

It stores only an OAuth refresh token so uploads can run on a schedule. The token is kept privately by the channel owner and is never sold or shared with third parties.

Use of Google user data

Data obtained through Google APIs is used only to upload videos to the owner's channel, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
